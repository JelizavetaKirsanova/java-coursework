# Java Programming Coursework

A collection of Java programming exercises completed as part of the
IT Systems Development curriculum at Tallinn University of Technology (TalTech).

## Topics Covered

- Java fundamentals and type system
- Object-Oriented Programming (OOP)
- Inheritance and polymorphism
- Exception handling
- Generics
- Java Collections Framework
- Functional programming
- Unit testing with JUnit

## Repository Structure

| Directory | Topic |
|-----------|-------|
| `intro` | Java fundamentals |
| `types` | Types and data handling |
| `oo` | Object-Oriented Programming |
| `inheritance` | Inheritance |
| `poly` | Polymorphism |
| `exceptions` | Exception handling |
| `generics` | Generic programming |
| `collections` | Java Collections Framework |
| `fp` | Functional programming |
| `junit` | Unit testing with JUnit |
